# EZSSH v0.0.7

> 发布日期：2026-09-14

本版本聚焦「桌面服务器可视化」与「文件管理器 / Docker 易用性」，并移除 AI 与地图相关功能。

---

## ✨ 新增功能

### 1. 桌面服务器「卡片模式」
- 桌面空白处右键菜单、或应用中心新增的「🗂️ 卡片模式」卡片，可在 **卡片模式 / 图标模式** 之间切换（记忆在本地）。
- 卡片以毛玻璃样式展示：在线状态点、系统 Logo、国家/地区国旗、名称、`用户@地址:端口`、微型监控（CPU/内存/硬盘、上下行速率、总流量）。
- **卡片支持左键拖动到任意自定义位置**（独立保存，并支持「自动对齐」吸附到网格）。

### 2. 服务器价格
- 新增主机价格设置：**金额 + 币种（¥ 人民币 / $ 美元 / € 欧元）+ 计费周期（每月 / 每年 / 每三年 / 一次性）**。
- 卡片底部以角标展示紧凑格式，例如 `¥99/年`；主机管理列表新增「价格」列。
- 角标配色：**价格 = 紫色文字 + 浅紫背景**。

### 3. 服务器到期时间提醒
- 新增主机**到期日期**设置，卡片显示剩余天数，例如 `余366天`；主机管理列表新增「到期时间」列。
- 到期状态分级高亮：正常 = **绿色文字 + 浅绿背景**，临近到期（≤7 天）= 橙色，已过期 = 红色。
- 桌面图标的悬浮提示同样展示价格与到期时间。

### 4. 文件管理器
- **拖拽上传**：直接把本地文件拖到窗口内即可上传（支持多文件；拖到某个文件夹行可上传到该文件夹），拖动时显示目标目录提示浮层。
- 「上传」按钮支持**多选文件**，并显示 `(i/n)` 队列进度。
- **右键任意文件或文件夹均可「刷新」**（此前仅空白处/文件夹支持）。
- 左侧「**快速访问**」中的文件夹支持**上下拖动调整顺序**，顺序持久化到网关（跨浏览器同步）。

### 5. Docker 管理
- 原「自定义安装」更名为「**自定义安装（设置配置）**」（可视化填写镜像、端口、环境变量、数据卷等）。
- 新增「**自定义安装（docker run）**」：直接粘贴一键安装命令即可创建容器。
  - 支持从文档复制的多行写法（反斜杠续行会自动合并）；
  - 仅接受单条命令且必须以 `docker run` 开头（可带 `sudo`）；
  - 复用终端式安装进度窗口，实时输出拉取镜像等日志。

---

## 🗑️ 移除功能

- **移除 Pi-Agent（pi-SSH-Agent / `pissh`）**：包括前端应用、后端 `/api/agent/*` 接口、`scripts/install-pissh.sh` 安装脚本、CLI 卸载联动逻辑及相关文档。
- **移除「世界地图」应用**：包含世界地图散点图、地图资源文件与相关词条（桌面图标的国家/地区国旗不受影响）。
- **移除 Gitee 镜像**：Gitee 仓库不再维护，删除 Gitee 安装脚本与文档中的 Gitee 源；请使用 GitHub Releases 或 Docker Hub 安装。

---

## 🔧 其他

- 数据库自动迁移：`hosts` 表新增 `expire_at`、`price`、`currency`、`billing_cycle` 列，旧库升级后自动补齐，无需手动处理。
- 新增 Docker 安装命令归一化的单元测试。

## 📦 安装方式

**一键安装（Linux / macOS / Windows(msys)）**

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/pureages/EZSSH/main/scripts/install.sh)
```

**Docker**

```bash
docker run -d --name ezssh -p 49466:49466 \
  -v ezssh-data:/app/data \
  pureages/ezssh:0.0.7
```
